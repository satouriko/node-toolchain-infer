## 最终范围表示

按用户最终确认：**稳定版本用范围，预发布仍按主/次/补丁号合并兼容范围，各组单独列出**。例如 `>=9.0.0 || >=9.0.0-rc.0 <9.0.0 || >=9.1.0-0 <9.1.0`。预发布组始终保留自己的上界，不并入稳定版；新增稳定版上界只修改稳定版子句。审计修改前的旧表达式仍原样保存。

## 保留的真实边界与不确定性

npm 12 移除 shrinkwrap 支持、pnpm 8 拒绝 5.x、pnpm 9 alpha.5–beta.3 不接受 v6、pnpm 10 rc.0 起拒绝 v6，以及 Yarn 的 metadata/cache/checksum 迁移，仍按原明确行为保留。不能把所有失败一律登记成 bug。

Yarn Classic 没有确定的稳定版下界；Yarn v7 只有 4.0.0-rc.1–rc.45 的支持区间，且早期稳定版本仍有未知。这两项按现有编译契约不发布部分限制，infer 保持 `*`。完整成功/失败点留在报告中，没有把 rc 当成不支持。

未知点包括缺失官方制品、历史工具启动失败、实际版本标签不符、不能证明冻结行为的控制实验、运行环境问题。不能把“查明为何没有结论”写成“已实测支持”。此处基线平台为 macOS，具体 Node、工具完整性、输入摘要和控制实验均在原始记录。

## 可复现方法

`pnpm data:audit --report maintenance/evidence/gap-audit/compiled/report.json --json maintenance/evidence/gap-audit/inventory-after.json --markdown maintenance/evidence/gap-audit/inventory-after.md` 重新生成最终全量清单。

编译时传入所有原始目录及本次 `gap-audit/pnpm`、`gap-audit/yarn` 目录；精确命令保存在 [compile-command.txt](compile-command.txt)。退出 2 表示仍有明确列出的未知证据，不能为追求退出 0 删除这些记录。

`rows/`、`logs/`、官方来源快照、复现脚本、输入/输出文件与指纹留在维护仓库。已确认误测以原 row SHA-256 精确排除；安装器 bug 以 observation 指纹登记。新证据追加，不改写旧日志或将失败伪装成 pass。
